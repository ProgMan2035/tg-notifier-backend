# TG Notifier Backend

Это тестовый бэкенд для запуска TG Notifier Frontend, если GREEN-API по какой-то причине не работает или в проекте есть ошибки. Прошу сообщить, если будут какие-либо ошибки с моей стороны.

## Интсрукция для локального запуска проекта

1. Скопировать репозиторий. 
2. Запустить локальный сервер: 

```
node server.js
```
